# 长图切分工具

一个本地运行的长图自动切分工具。推荐直接使用网页版：无需安装依赖，图片只在浏览器本机处理，不会上传到网络。

## 主要功能

- 自动结合留白、低纹理过渡、深色分隔带、拼接缝和 RGB 色彩分界识别切口
- 不够长的图（如两张横图上下拼接）也会识别明确的拼接缝自动切开；没识别到的可勾选后采用建议切口或手动添加
- 参考相邻切片的典型高度，重新识别指定范围
- 原图与切分效果双栏预览，均可独立缩放
- 手动添加、删除、拖动切分线，并可用键盘逐像素微调
- 单张切片支持放大、裁剪、删除、撤销和重做
- 手动切口及效果编辑自动保存到浏览器，下次重新选择同一源文件夹时恢复
- 批量处理、包含子文件夹、只试切前 5 张、切分记录 CSV
- 源图片始终只读；结果写入独立的 `<原文件夹名>切分结果` 文件夹

## 使用方法

1. 下载本仓库，使用最新版桌面版 Google Chrome 打开 `长图切分.html`。
2. 点击“选择文件夹”，选择待处理的原图文件夹。
3. 点击“选择保存位置”，选择一个不在原图文件夹内部的位置。
4. 等待自动分析完成。点击图片所在行，可对照查看原图和切分效果。
5. 检查并调整切口，勾选需要处理的图片后点击“开始切分”。

工具会在所选保存位置中创建：

```text
<原文件夹名>切分结果/
├── <图片 1 文件名>/
│   ├── <图片 1 文件名>_01.jpg
│   └── <图片 1 文件名>_02.jpg
├── <图片 2 文件名>/
└── 切分记录.csv
```

结果目录只包含切片和切分记录，不复制原图，也不生成对照图。

## 精细调整

- 点击原图空白位置：添加切分线
- 短按已有切分线：删除
- 长按或直接拖动切分线：上下移动；靠近检测到的边界时自动吸附
- 按住 `Option` 拖动：临时关闭吸附
- 右键选择切分线后按 `↑` / `↓`：移动 1 像素
- `Shift + ↑` / `Shift + ↓`：移动 10 像素
- `←` / `→`：查看上一张或下一张
- 右侧选择切片范围后点击“重新识别”：按周围切片高度和图像分界重新规划
- 点击右侧切片：打开大图，可裁剪或删除；`⌘/Ctrl + Z` 撤销

所有手动调整会自动保存在当前浏览器的 IndexedDB 中。原图发生变化后，旧记录会自动作废。清除浏览器网站数据或更换浏览器后，本地调整记录不会保留。

## 安全说明

- 网页版是一个静态 HTML 文件，不包含网络请求，图片不会离开本机。
- 源文件夹仅申请读取权限，不修改、移动或删除原图。
- 保存位置单独申请写入权限，且不能选择源文件夹或其内部目录。
- “覆盖已有结果”或在单图窗口中重新生成时，会替换对应结果子目录内由本工具命名的旧切片；建议使用专门的结果目录。
- 浏览器关闭前仍在保存调整时，页面会给出离开提醒。

## 浏览器要求

文件夹读写依赖 File System Access API。推荐：

- 最新版桌面 Google Chrome
- 其他新版 Chromium 浏览器可能可用

Safari 和 Firefox 目前不支持本工具所需的完整文件夹读写接口。

## 基础命令行版

仓库还保留了较早的 Python 命令行版本，适合无界面的批处理。它不包含网页版的完整预览和编辑能力。

```bash
python3 -m pip install -r requirements.txt
python3 长图切分.py "/路径/到/原图文件夹"
```

查看全部参数：

```bash
python3 长图切分.py --help
```

## 支持格式

网页版可读取 JPG、JPEG、PNG、WebP、BMP 和 GIF。JPEG、PNG、WebP 保持对应输出格式，其他格式转换为 PNG。
